Unity Project Summary:
1. Framework: Universal Render Pipeline (URP) with New Input System.
2. Structure: Standard Unity folders (Assets, Packages, ProjectSettings). 
3. Settings: Dual RP assets for PC and Mobile scalability.
4. Input: Player actions (Move, Look, Attack, Jump, Sprint, etc.) are pre-configured.
5. Missing: A dedicated Assets/Scripts folder for game-specific logic.

GitHub Branches (Feature-Branch Workflow):
- dev: Main development branch.
- feature/chaos-layer: Specific work on the chaos layer feature.
- feature/player-movement: Specific work on player movement mechanics.
