TRIGGER RULE:

* Every 10–20 score interval:
  triggerRandomEvent()

CONSTRAINTS:

* maxActiveEvents = 2
* eventDuration = random(3–8 seconds)

EVENT OBJECT STRUCTURE:
{
eventName: string,
duration: float,
isActive: bool
}

---

## EVENT EXECUTION TEMPLATE (PSEUDOCODE)

function triggerRandomEvent():
if activeEvents.count >= 2:
return

event = getRandomEvent()
activate(event)

---

function activate(event):
event.isActive = true
add to activeEvents

wait(event.duration)

deactivate(event)

---

function deactivate(event):
event.isActive = false
remove from activeEvents
